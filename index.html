Steam Deck Screenshots

A personal backup tool that copies Steam screenshots from a Steam Deck to its owner's Google Drive.

The tool runs on the Deck. It saves pending screenshots locally while offline and retries when an internet connection is available. Images are grouped by game, and the original screenshots stay on the Deck.

Google Drive access

Google sign-in gives the tool access only to the specific Drive files it creates or that are explicitly opened with this app. It does not request access to all files in the account.

Backups go to the owner's private Steam Deck Screenshots folder. There is no public screenshot gallery or public account registration.

Read the privacy policy. For questions about this personal project, contact the project owner on GitHub.

This project is independent of Valve and Google. This information site does not handle sign-in or store screenshots.
